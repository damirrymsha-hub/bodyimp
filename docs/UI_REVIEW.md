# Упрощение интерфейса — 28 сентября 2026

Сохранены две вкладки, существующие данные и способы добавления еды.

## Изменения

- Питание: четыре постоянных блока приёмов пищи, одна кнопка добавления на блок; читаемые значения макросов и названия блюд.
- Календарь: явные кнопки предыдущей/следующей недели и возврата к сегодня в дополнение к свайпу.
- Меню еды: компактная сетка способов, отдельная строка повторения вчера, недавние блюда ниже; возврат из каждого способа без закрытия всего окна.
- Активность: одна заметная кнопка добавления, убрана произвольная цель расхода 600 ккал. Ошибка сохранения оставляет форму открытой.
- Профиль: короткое название уровня активности и полное пояснение ниже; переключатели сообщают выбранное состояние.
- Поиск: отдельные состояния загрузки, ошибки с повтором и пустого результата; запоздалые ответы не заменяют новый запрос.
- Увеличены мелкие подписи и контраст, высота кнопок не менее 44 px, основные поля 16 px; разрешено масштабирование страницы.
- Диалоги удерживают фокус, поддерживают Tab/Escape и возвращают фокус после закрытия. Вложенные формы и камера закрываются по очереди. Учтена настройка уменьшения движения.
- История и избранное доступны с клавиатуры; у полей и кнопок с иконками добавлены доступные названия.

## Проверено

- `npm run build`: успешно; входной JS 239 452 байта (лимит 250 000). С зависимостями дневника — 256 987 байт; внешний SDK не входит в эту цифру.
- `npm test`: 45 тестов, включая вложенные окна, возврат фокуса и ошибку сохранения активности.
- `scripts/browser-smoke.cjs`: реальная production-сборка с синтетическими API-ответами; ширины 320/390/1024, календарь без свайпа, вложенная порция, Escape/Tab, фото/текст с подтверждением и выбранным приёмом пищи, профиль/прогресс. Горизонтального переполнения и ошибок JavaScript не обнаружено в проверенных сценариях.
- Визуально просмотрены дневник, меню еды, активность и профиль.

Проверка браузера выполнена в Chromium с мобильным viewport; это не проверка физического iPhone, камеры или точности внешней ИИ-модели и не полный аудит соответствия WCAG.
