# Экономия квоты Neon и удаление напоминаний

28 сентября 2026.

- GET/HEAD `/` проверяет только доступность процесса. Проверка схемы `users` удалена: пинги Render больше не запускают запросы к Neon.
- Фоновая рассылка напоминаний и её планировщик полностью удалены. Настроек напоминаний в профиле и регистрации больше нет.
- Старые колонки уведомлений оставлены в БД для совместимости, но не используются и не возвращаются API профиля. Команды Telegram-бота сохранены.
- При временной недоступности БД старт HTTP-сервера продолжается. Следующая попытка инициализации возможна только при запросе, которому нужна БД, не чаще раза в 15 минут. Пинг не запускает повторных попыток.
- Ошибка подключения к БД возвращается как безопасный 503 без SQL и секретов.

Проверки: 4 серверных теста `test_idle_database.py`, 45 frontend-тестов, TypeScript/Vite build. Серверные тесты не подключаются к рабочей БД и не отправляют сообщения.

Эти изменения не восстанавливают исчерпанную месячную квоту. До её обновления или изменения тарифа чтение профиля и дневника остаётся недоступным.
