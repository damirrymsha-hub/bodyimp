# BodyImp v2 — происхождение иллюстраций и лицензии

Исследование от 28.09.2026. На этом этапе изображения не импортировались и не создавались.

## Выбор владельца

**Единые схематичные иллюстрации.** Этот ответ разрешает подготовку собственных схем на этапе библиотеки. Для каждой карточки — начало и конец движения, одинаковый ракурс, контрастная фигура, стрелки движения; подпись техники остаётся текстом. Схема не должна изображать болезненную/опасную амплитуду как обязательную.

Предложение: оригинальные векторные исходники, экспорт в WebP фиксированного размера, два изображения на упражнение, lazy loading. Отдельно проверить мобильную читаемость. Не обводить чужие изображения без разрешения. Каждая схема проходит проверку соответствия упражнению; генерация изображения сама по себе не подтверждает анатомическую корректность.

## Реестр каждого будущего файла

До включения в build записать: exercise_id, имена файлов start/end, автор/способ создания, дата, лицензия/права, исходный URL (если заимствован), snapshot/commit источника, необходимые подписи, выполненные изменения, размеры, hash, кто проверил технику. Для собственных схем URL чужой базы не нужен; происхождение всё равно фиксируется.

Сейчас записей импортированных файлов **0**. Это исследование вариантов, не сертификат прав на ещё не выбранные изображения.

## Реализация 01.10.2026 — инструкции упражнений

Созданы собственные кодовые SVG-схемы для всех 26 ID в `backend/data/training_exercises.py`, по две фазы на упражнение (52 состояния). Исходники: `frontend/src/components/exerciseGuides.ts` (позы и тексты) и `ExerciseInfo.tsx` (векторный рендер). Происхождение: оригинальные координаты суставов, опор, оборудования и стрелок, созданные агентом для BodyImp; чужие изображения и обводки не использованы, внешних требований атрибуции изображений нет. Версия фиксируется Git-коммитом этих файлов; PNG/WebP в приложение не добавляются. ViewBox 240×240, масштабируется без потери чёткости.

Это схематичный боковой ракурс, а не анатомическая модель. Варианты сидя/лёжа, с колен/носков, на скамье/полу сопоставлены явно. Подготовка и техника написаны отдельно для различающихся вариантов. Сверка общих движений: [ACE Exercise Library](https://www.acefitness.org/resources/everyone/exercise-library/); числовые назначения из этой страницы не заимствованы. Схемы не являются копиями материалов ACE.

Проверка: визуальный просмотр обеих галерей 26 упражнений агентом, исправлены опоры на полу/скамье, положение колен и стрелки; независимая экспертиза тренером не выполнялась. Автотест сопоставляет ID с серверным каталогом, проверяет две фазы и наличие инструкции. `scripts/exercise-guides-review.cjs` открывает 26 настоящих окон из production-сборки с локальным тестовым API и сохраняет галереи обоих состояний. `browser-smoke.cjs` проверяет окно на 320 px, переключение фазы, Escape и возврат фокуса. Исторический/неизвестный ID получает только свои сохранённые текстовые подсказки, без подстановки чужой иллюстрации.

Инструкция открывается кнопкой ⓘ размером 44×44 px и загружается отдельным ленивым чанком. Внешних запросов к сайтам с картинками нет.

По дополнительному запросу добавлена управляемая SVG-анимация: полный повтор за 6 секунд, плавное движение туда и обратно, запуск/пауза, перемотка, скорость 1×/0,5×. Видео-файлы не загружаются: кадры строятся локально из тех же собственных координат. Автовоспроизведения нет; скрытие вкладки и закрытие окна останавливают requestAnimationFrame. Анимация представляет схему движения, не физическую симуляцию суставов и не индивидуальный эталон амплитуды. Рекомендуемый темп реального подхода не выводится из длительности цикла.
