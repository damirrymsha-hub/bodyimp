# BodyImp v2 — этап 1: навигация и облегчение

28 сентября 2026. Основа: `b0c96bc`.

## Изменения

- Две вкладки: «Питание» и «Активность», общая выбранная дата.
- Фото и текст открываются прямо с дневника. «Ещё» содержит поиск, штрихкод, ручной ввод, избранное, недавние блюда и выбор вчерашних записей.
- Профиль открывается через аватар, прогресс — из профиля. Трекер воды и его норма удалены из интерфейса; исторические данные, API и текущие напоминания сохранены.
- Существующий журнал активности вынесен во вторую вкладку. Генератор недельных программ относится к следующему этапу, фиктивных тренировок сейчас нет.
- Страницы, добавление еды и его режимы загружаются отдельно. Ошибка загрузки чанка имеет понятный экран восстановления.
- SDK Telegram из HTML используется без второй копии в основном JS. Локальная копия загружается при недоступном CDN. Перехват initData остаётся первым импортом, BrowserRouter и безопасное хранилище сохранены.
- Исправлены гонка ответов разных дней и преждевременный переход существующего пользователя в онбординг при холодном старте.
- Неиспользуемый Recharts удалён. Единственная схема Zod заменена небольшой проверкой полей с тестами. Terser добавлен только как инструмент сборки.

## Размеры

Vite production, минифицированный JavaScript, десятичные КБ (1000 байт), без HTTP-сжатия:

| Метрика | До | После |
|---|---:|---:|
| Основной JS | 563,89 КБ | 238,00 КБ |
| JS приложения для первого дневника, включая статические зависимости Home | 563,89 КБ | 254,98 КБ |
| Основной JS, gzip | 170,85 КБ | 80,19 КБ |
| Форма добавления | в основном JS | 14,31 КБ |

Основной чанк меньше 250 КБ; полный первый дневник — около 249 КиБ (254,98 десятичных КБ). Скрипт `scripts/check-bundle.mjs` считает обе метрики, проверяет бюджет основного JS и наличие ленивых страниц. В таблицу не входят CSS, шрифты и внешний Telegram SDK, присутствовавший и до изменения. Если CDN SDK недоступен, локальный резерв добавляет около 51,97 КБ. Это не скрывается за метрикой одного чанка.

## Проверки

- Vitest: 42 теста, включая 22 прежних; перехват initData, iOS storage, сетевой fallback, гонка дат, холодный старт, фото/текст и выбранный приём пищи.
- TypeScript и production build: успешно.
- `backend/tests/test_schema.py`: успешно, PostgreSQL BIGINT для современных Telegram ID сохранён.
- `scripts/browser-smoke.cjs`: Chromium с мобильным экраном 390×844, реальная production-сборка и синтетические API-ответы. Проверены холодный старт, локальный fallback SDK, загрузка фото, подтверждение текста, правильные приёмы пищи, две вкладки, профиль и прогресс. Изменений рабочих данных не выполняет.
- Скриншоты питания и активности просмотрены. Эта проверка не заменяет испытание реальной камеры и Telegram WebView на физическом iPhone, выделенное в этап 6; настоящая модель ИИ в этом тесте не вызывается.

Повторный запуск:

```powershell
cd frontend
npm ci
npm test
npm run build
npm run preview -- --host 127.0.0.1 --port 4173
# В другом терминале, с установленным Playwright:
node scripts/browser-smoke.cjs
```

Для готового внешнего рантайма тест принимает `BODYIMP_PLAYWRIGHT_PATH`, `BODYIMP_BROWSER_PATH`, `BODYIMP_TEST_OUTPUT`. Подменять production URL в тесте нельзя: сетевые запросы ограничены localhost.
